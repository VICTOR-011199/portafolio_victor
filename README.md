#  Portafolio Web | Victor Mariño

Bienvenido a mi portafolio web personal.  
Este proyecto fue desarrollado con HTML5 y CSS3 para presentar mi perfil profesional, habilidades y objetivos como desarrollador web en formación.

Descripción del Proyecto

Este portafolio es una página web estática diseñada para mostrar:

- Información personal
- Perfil profesional
- Habilidades técnicas
- Formación académica
- Objetivos profesionales
- Información de contacto


 Tecnologías Utilizadas

- **HTML5** — Estructura del sitio web  
- **CSS3** — Diseño, estilos y responsividad  
- Assets — Imágenes y recursos visuales
